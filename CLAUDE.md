# CLAUDE.md — точка входа при работе внутри клона

Репозиторий содержит **AI-скилл `vkr-mpgu` версии `6.33-production`** — инструкцию
и инструменты для подготовки, оформления и проверки ВКР по методическим
рекомендациям МПГУ и ГОСТ. Файл читает Claude Code, когда работает внутри клона
репозитория; те же правила в платформенно-нейтральном виде — в
[AGENTS.md](./AGENTS.md).

## Нормативная инструкция

- [vkr-mpgu/SKILL.md](./vkr-mpgu/SKILL.md) — главный документ скилла, читается до
  начала работы.
- [vkr-mpgu/references/quickstart.md](./vkr-mpgu/references/quickstart.md) —
  сквозной путь с командами.
- [README.md](./README.md) → «Инструкция для ИИ-агента» — блок
  `AI_AGENT_BOOTSTRAP`, единственный источник правил запуска; ниже только выжимка.
- [vkr-mpgu/references/platform-integration.md](./vkr-mpgu/references/platform-integration.md)
  — различия платформ и деградация независимости аудита.

## Ключевые правила

1. Рабочие файлы ВКР — в отдельной папке проекта `<PROJECT_DIR>`, не в клоне
   скилла; папку скилла во время работы пользователя не редактируй.
2. Новый проект: intake (с правилами кафедры об ИИ) → `intake.json` →
   `init_vkr_project.py`; существующий — сначала `vkr_memory.py status` и
   `vkr_audit.py next`, потом работа.
3. Текст — в `drafts/*.md`, сборка — `build_vkr.py`, сдаётся только
   `final/vkr.docx`.
4. Источники подтверждай веб-поиском и отмечай `verify_sources.py --mark`; не
   выдумывай источники, результаты, пилоты и подписи.
5. Аудит — только командами `vkr_audit.py`: аудиторы read-only, исправляет
   основной агент.
6. `READY_TO_SUBMIT` выдаёт только `vkr_project_doctor.py --stage final`.

## Вызов и независимый аудит

Вызов: `/vkr-mpgu помоги начать ВКР с нуля` или обычный запрос о ВКР. Если скилл
установлен отдельно (`~/.claude/skills/vkr-mpgu`) и одновременно подключён в
аккаунте платформы как `anthropic-skills:vkr-mpgu`, отключи одну из копий —
иначе загрузятся две версии (см. [vkr-mpgu/INSTALL-RU.md](./vkr-mpgu/INSTALL-RU.md)).

Для независимого аудита запускай субагентов (Task) — по одному на задание из
`vkr_audit.py brief`, аудитору давай только чтение и поиск. Без отдельных
контекстов аудит помечается `degraded_independence`, и итог не выше
`READY_FOR_SUPERVISOR_REVIEW`.

## Разработка самого скилла

Полный набор тестов из корня репозитория:

```bash
python -m unittest discover -s tests -t .
```

Тесты не ходят в сеть и не пишут в каталог скилла.
