# Проверка готовности `vkr-mpgu 6.28-verified`

## Решение

Сборка готова к рабочему применению для обычной и проектной ВКР направления
09.03.02 ИМО МПГУ при выборе соответствующего профиля. Исходный процесс
`6.26-friends` сохранён. Внесены платформенный слой и точечные исправления,
которые подтверждены предоставленными документами или устраняют воспроизводимые
ошибки скриптов.

Версия 6.26 с одной только переносимой адаптацией и версия 6.27 предыдущего
аудита сохранены отдельными архивами. Поэтому ни один проверенный вариант не
перезаписан.

## Основной нормативный документ

Основой профиля 09.03.02 является предоставленный файл:

`Мет_рек_ции_по_нап_ю_ВКР_в_формате_проекта_и_обычной_ВКР_для_09.docx`

- содержание: требования ИМО МПГУ к обычной и проектной бакалаврской ВКР;
- внутренние даты DOCX: 3 сентября 2024 года;
- SHA-256: `8d890c1474c0621a8e5259b514126935c92d94393127c2d27094fa80cb447eae`;
- точная копия в скилле: `assets/methodology-09-03-02-2024.docx`;
- хеш исходника из Downloads, рабочей копии, файла в папке скилла и файла в
  распакованном архиве совпадает.

Два имени файла в Downloads отличаются только Unicode-нормализацией и имеют
одинаковое содержимое. Повторно приложенные документы другого направления и
форма справки также оказались точными дублями ранее проверенных файлов.

## Исправления скриптов

1. `create_vkr_docx.py` теперь явно задаёт A4 210×297 мм. До исправления
   `python-docx` создавал Letter 215,9×279,4 мм при правильных полях.
2. `validate_vkr.py` проверяет размер страницы во всех секциях.
3. Добавлены профили `generic`, `mpgu-09-regular`, `mpgu-09-project`.
4. В проектном профиле проверяются три главы, пилот и образовательная рамка.
5. Порог пяти участников применяется строго к частной практике.
6. Исправлено распознавание числа участников в развёрнутой фразе и единственного
   числа «1 источник» в аннотации.

Рендер через LibreOffice недоступен, потому что LibreOffice не установлен.
Невидимый экспорт через установленный Word завис на локальном диалоге запуска и

поля и повторное открытие DOCX; визуальная проверка конкретной итоговой ВКР в
Word остаётся обязательным последним шагом.

## Порядок применения

Для проектной ВКР 09.03.02:

```bash
python scripts/validate_vkr.py vkr.docx --profile mpgu-09-project
```

Для обычной ВКР 09.03.02:

```bash
python scripts/validate_vkr.py vkr.docx --profile mpgu-09-regular
```

После генерации нужно открыть файл в Microsoft Word, обновить содержание целиком
клавишей F9 и повторно запустить валидатор. Перед реальной сдачей также нужно
подставить актуальный титульный лист, проверить требования текущего года и
утверждённый научным руководителем план. Эти документы имеют приоритет над
встроенным профилем 2024 года.
